## 📖 简介

**OneDeck** 是一款专为 iOS 平台打造的旗舰级工业工控硬件遥测、环境感知与诊断控制台。基于原生 **SwiftUI** 与 **Darwin / Mach Kernel / IOKit** 底层通道构建，深度整合高频传感器、电芯管理系统 (BMS)、底层网络协议栈与高精度微机械测量仪器。

> [!NOTE]
> 全站严格遵循 Apple 人机界面指南 (HIG) 与工控仪表面板标准，无多余阴影干扰，排版自适应无截断，100% 本地运算，零远程数据采集与广告追踪。

## ⚡️ 核心功能模块

### 1. 概览看板 (Overview)
- **SoC 芯片与温控**：实时芯片结温、电芯温度、整机温控热压等级（正常、温热、较热、过热）。
- **CPU 监视器**：60Hz 实时动态负载曲线图，P 核（性能核）与 E 核（能效核）协同状态。
- **内存与存储**：活跃、联动、压缩、空闲物理 RAM 细分图表；一键释放临时系统缓存。
- **实时网络带宽**：30s 动态双向网速流，自动识别当前网络接口与基带状态。
- **全量硬件档案**：读取台积电先进制程（nm）、指令架构（ISA）、GPU 核心数、Metal 3 硬件光追、神经网络引擎算力（TOPS）、Face ID / Touch ID、安全隔区（SEP）。

### 2. 电池遥测 (Battery & Thermals)
- **BMS 原厂真值**：支持直接读取或解析官方分析日志（`.ips`），解锁真实循环次数与电芯健康度。
- **实时供电功率**：动态显示实时电压（V）、电流（mA）、充放电瞬时瓦数（W）与协商协议（USB-PD 快充、涓流维护、电池放电）。
- **机身热力透视**：红外热像 (FLIR) 与透视蓝图双模，四分区温敏监测（SoC 主板、锂电芯主仓、快充供电模组、磁吸无线线圈）。
- **容量衰减轨迹**：循环次数与容量保留率走势图，标出 80% 官方检修线。

### 3. 网络内核 (Network & Diagnostics)
- **链路信息**：局域网 IP、子网掩码、默认网关、DNS 服务器、MTU 与协商速率。
- **多节点 DNS 基准测速**：并发探测主流公共 DNS 解析延迟与最快节点。
- **公网出口与运营商**：实时探测公网出口 IP、运营商归属地及代理通道状态。
- **局域网发现 (mDNS)**：自动扫描本地活动 Bonjour 服务与局域网终端。
- **网络唤醒 (Wake-on-LAN)**：POSIX UDP 广播 102 字节唤醒魔术包。
- **端口与域名解析**：常用服务端口扫描器，POSIX 原生 A 与 AAAA 记录解析。

### 4. 工业工具箱 (Tools & Instruments)
- **双轴水平仪**：横滚角 (X) 与俯仰角 (Y) 高精度解算，支持倾角与坡度 (%) 转换、0.0° 声学与触感对准提示。
- **屏幕物理卡尺**：1:1 原生物理换算（公制 mm / 英制 inch），支持双游标自由测量与常用实物基准。
- **声波共振排水**：165Hz 低频声学物理排水与 440Hz 扬声器振膜除尘。
- **精细手电调光**：1% ~ 100% 线性流明微调、SOS 国际莫尔斯电码信标与旋转测速频闪仪。
- **金属与电磁寻线**：三轴地磁磁通感应示波器，实时监测电磁场波动与金属靠近。
- **气压与相对海拔**：实时高精度大气压强 (hPa)、相对高程差计与升降垂直速度 (VSI)。
- **纯音频发生器**：20Hz ~ 20,000Hz 纯正弦波/方波/三角波发生器与听力生理年龄测定。
- **屏幕触控与坏点质检**：纯色全屏漏光/坏点巡检、120Hz 全屏网格触控轨迹连贯性采样。
- **触觉马达测试**：Taptic Engine 线性致动器多级冲击感与拨轮机械阻尼测试。
- **环境噪声分贝计**：实时声压等级 (dB SPL)、动态波形、峰值与平均环境噪声监测。
- **电子罗盘与微震烈度**：地磁航向罗盘、三轴地动加速度与地震烈度等级。
- **光电容积脉搏波 (PPG)**：摄像头光电容积波心率测量与 HRV 变异性分析。
- **环境照度计 (Lux)**：环境流明 (Lux)、尺烛光 (fc) 与 EV 曝光值实时换算。
- **卫星导航 (GNSS Hub)**：多模差分状态、HDOP/VDOP 几何精度因子与多制式坐标基准转换。
- **蓝牙雷达与工业微距**：近场 BLE 信号测距、后置镜头微距探伤与边缘滤波。

### 5. 系统与设置 (Settings)
- **外观模式下拉菜单**：支持【跟随系统】、【浅色】、【深色】标准下拉菜单选择。
- **主题强调色调色板**：原生取色器结合十六进制 HEX 色值实时编辑。
- **纯硬件应用图标**：提供 4 款纯几何无文字工控图标（默认翡翠、极夜暗黑、赛博霓虹、工业热力），支持 iOS 原生动态切换。
- **多语言下拉菜单**：跟随系统、简体中文、繁體中文、English 完整对称覆盖。
- **偏好设置**：Taptic 触觉反馈开关、水平仪对准提示音开关、低电量遥测节流、IMU 传感器零位校准。
- **证书与签名管理**：内核级解析 `embedded.mobileprovision`，实时显示 7 天/365 天倒计时、团队标识、证书类型（免系统跳转干扰）。
- **开源协议与诊断导出**：MIT 许可证完整条款查看、一键复制全量硬件诊断摘要。

## 🛠️ 构建与开发环境

### 系统与工具要求
* **macOS**：macOS 14.0 (Sonoma) 或更高版本
* **Xcode**：Xcode 15.0+ (Swift 5.9+)
* **目标系统**：iOS 17.0+ (iPhone / iPad)

### 编译运行
1. 克隆代码仓库：
   ```bash
   git clone https://github.com/binbankm/OneDeck.git
   cd OneDeck
   ```
2. 打开 Xcode 工程：
   ```bash
   open OneDeck.xcodeproj
   ```
3. 在 Xcode 中配置您的个人或开发者团队签名（Signing & Capabilities）。
4. 连接 iOS 目标设备或选择 iOS 模拟器，点击 **Run (⌘R)** 即可完成构建与部署。

## 🔒 隐私与安全承诺

OneDeck 秉承“**本地运算、绝对透明、零隐私收集**”的原则：
- **完全本地化**：所有传感器、电芯、网络及硬件遥测均在本地沙盒与内核管道内运算。
- **零追踪**：不含任何第三方广告 SDK、用户画像或云端统计埋点。
- **不上传**：设备序列号、MAC 地址、网络流量与诊断数据仅保存在本地设备内存中，不会上传至任何远程服务器。
